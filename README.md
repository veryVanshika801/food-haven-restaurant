
# Food Haven - Restaurant Menu Website

Food Haven is a simple restaurant menu website created using HTML and CSS. It displays different food categories, popular dishes, special offers and restaurant information.

## Features

- Home page with restaurant introduction
- Food categories and menu sections
- Food images, descriptions and prices
- Chef's special dishes
- Special offers and combo meals
- About Us section
- Contact information and message form
- Responsive layout for different screen sizes

## Technologies Used

- HTML5
- CSS3

## Project Structure

Food-Haven/
│
├── index.html
├── style.css
├── images/
│   └── restaurant.jpg
└── README.md

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Make sure the `images` folder contains `restaurant.jpg`.
4. Open `index.html` in your browser.

## Note

This project is a beginner-level static website. It uses HTML and CSS without JavaScript or backend functionality.
